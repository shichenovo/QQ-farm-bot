========================================
qq-farm-bot  NapCat 对接版  — 部署步骤
========================================

包含内容：
  - 完整源码（core 后端 + web 前端 + napcat/ + napcat-bridge/）
  - 已构建产物（web/dist、core/client.js、core/dist —— 已含 NapCat 对接代码）
  - Linux 一键部署脚本（server-deploy.sh、docker-compose.yml）
  - 详细文档（docs/LINUX-DEPLOY-NAPCAT.md）

------------------------------------------------
方式一：Docker 部署（推荐，Linux 服务器）
------------------------------------------------
前置：Docker 20+ / Docker Compose 2+，内存建议 2GB+（NapCat 的 QQ 是 Electron）

1. 上传解压：
   scp qq-farm-bot-napcat.zip root@<服务器IP>:/
   ssh root@<服务器IP>
   cd / && unzip qq-farm-bot-napcat.zip -d /opt/  (或任意目录)

2. 修改端口（默认 3007，要 3008 就这样）：
   export PORT=3008

3. 一键部署（构建 core + NapCat 镜像并启动）：
   bash server-deploy.sh

   或手动：
   docker compose up -d --build

4. 访问：http://<服务器IP>:3008   （admin / admin，首次登录请改密码）

5. 添加账号：设置 → 账号管理 → 添加账号 → 「QQ 扫码登录」(NapCat)
   用手机 QQ 扫码，成功即自动添加账号并挂机。

------------------------------------------------
方式二：Node 直跑（不构建镜像，轻量，适合小内存服务器）
------------------------------------------------
前置：Node 20+、npm，1GB 内存即可

1. 上传解压（同上）。

2. 装 core 依赖（只装 core，很轻）：
   cd core && npm install --omit=dev

3. 启动（端口用环境变量，默认 3007）：
   PORT=3008 node client.js
   或后台常驻：nohup node client.js > /tmp/farmbot.log 2>&1 &

4. 访问：http://<服务器IP>:3008

注意：方式二没有 NapCat 容器，「QQ 扫码登录」不可用（会提示桥接不可用），
只能输入 Code / 微信扫码登录。要 QQ 扫码必须用方式一（NapCat 容器）。

------------------------------------------------
NapCat 说明
------------------------------------------------
- NapCat 容器负责 QQ 常驻 + 扫码登录 + 农场 Code 授权（OpenAuth）
- Code 自动刷新两层机制：
    ① worker 报 400（登录失效）→ 自动刷 Code 并重连
    ② 每 60 分钟定时兜底刷新（FARM_AUTO_REFRESH_MINUTES 可调）
- 掉线检测：心跳状态机 + 指数退避自动重连（FARM_AUTO_RECONNECT=0 关闭）
- 登录态持久化：qq-farm-napcat-data 卷，容器重建不丢
- 单账号限制：当前架构同时只支持一个 QQ 常驻
- 换绑 QQ：清空卷后重部署（见 docs/LINUX-DEPLOY-NAPCAT.md §6）

------------------------------------------------
常见问题
------------------------------------------------
1. 服务器内存 < 2GB 时 docker 构建可能 OOM：
   先只起 core（docker compose up -d qq-farm-bot），NapCat 单独构建：
   docker build -f napcat/Dockerfile -t qq-farm-napcat:farm .   （限内存：docker build --memory 1g ...）
2. docker 拉镜像慢：配置镜像加速（/etc/docker/daemon.json 的 registry-mirrors）
3. 面板空白：Ctrl+F5 强刷（浏览器缓存旧 JS）
